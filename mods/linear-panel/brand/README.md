# Linear logo

`logo-light.svg` (white, for dark themes) and `logo-dark.svg` (for light themes) are Linear's logomark, unchanged, from
Linear's brand assets (<https://linear.app/brand>).

Linear and the Linear logo are trademarks of Linear. They are not this project's work, this project's MIT license does
not cover them, and this project is not affiliated with or endorsed by Linear. The panel shows the logo only to say
which service its issues come from.

Use the files as they are: show them with `image()`, not `svg()`, which would recolor them. The white one goes on dark
themes, the dark one on light themes.
